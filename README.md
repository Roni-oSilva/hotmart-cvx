# Carvex Technology: página de vendas (Hotmart)

Página única que apresenta os templates, painéis de leads e kits de orçamento da Carvex e leva o cliente à Hotmart.

- `index.html`: a página (arquivo único, abre direto no navegador).
- `assets/`: imagens da página.

## Links da Hotmart
Abra `index.html` e procure `var LINKS`. Cole o link de cada produto entre as aspas. Sem link, o botão abre o WhatsApp com o nome do produto.

## Publicar com GitHub Pages
Settings > Pages > Source: Deploy from a branch > Branch: `main` / pasta `/ (root)` > Save. O endereço será `https://roni-osilva.github.io/hotmart-cvx/`.

Este repositório contém apenas a página. Os arquivos dos produtos ficam em outro repositório, que deve permanecer privado.
